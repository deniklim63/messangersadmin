# Админка ботов

Общая база пользователей Telegram- и ВК-ботов: кто откуда пришёл, какие данные оставил,
из какого города. Один человек — одна карточка, даже если он написал в несколько ботов.

## Что умеет

- **Подключение ботов.** Telegram — webhook прописывается кнопкой из карточки бота.
  ВКонтакте — Callback API (адрес, строка подтверждения и секретный ключ).
- **Сбор данных.** Встроенная анкета спрашивает имя, телефон, e-mail и город.
  В Telegram телефон можно отдать кнопкой «Отправить мой номер».
- **Склейка людей.** Если телефон или e-mail совпал, записи из разных ботов
  объединяются в один контакт — видно, что человек есть и в TG, и в ВК.
- **Фильтры.** По городу, по боту, «есть в 2+ ботах», поиск по имени/телефону/e-mail/@username.
- **Выгрузка CSV** с учётом текущих фильтров.
- **История сообщений** по каждому человеку — задел под рассылки и чат.

## Запуск

```bash
npm install
npm run db:up        # Postgres в Docker, порт 5433
npm run db:migrate   # применить схему
npm run seed         # демо-данные, по желанию
npm run dev          # http://localhost:3100
```

Пароль входа — `ADMIN_PASSWORD` из `.env` (по умолчанию `admin`).
Полезные команды: `npm run db:studio` — Prisma Studio, `npm run db:reset` — чистая база с демо-данными.

## Настройки (.env)

| Переменная | Зачем |
| --- | --- |
| `DATABASE_URL` | подключение к Postgres |
| `ADMIN_PASSWORD` | пароль входа в админку |
| `AUTH_SECRET` | подпись сессионной cookie, в проде: `openssl rand -hex 32` |
| `APP_URL` | публичный адрес — из него строится webhook-URL для ботов |

## Как подключить Telegram-бота

1. Возьмите токен у [@BotFather](https://t.me/BotFather).
2. **Боты → Новый бот**, платформа Telegram, вставьте токен. Токен сразу проверяется
   через `getMe` — если он неверный, бот не создастся.
3. Задайте `APP_URL` — публичный **https**-адрес (Telegram не принимает http).
   Локально: `ngrok http 3100`, полученный адрес пропишите в `.env` и перезапустите `npm run dev`.
4. В карточке бота нажмите **Подключить webhook**. Строка статуса покажет, что Telegram
   принял адрес; ниже, в «Последних событиях», видно каждый входящий запрос.

## Как подключить сообщество ВКонтакте

1. Управление сообществом → Работа с API → Ключи доступа: создайте ключ с правами на сообщения.
2. **Боты → Новый бот**, платформа ВКонтакте, вставьте ключ.
3. В разделе Callback API вставьте адрес из карточки бота, скопируйте оттуда
   строку подтверждения и секретный ключ в поля админки, **сохраните**,
   и только потом нажмите «Подтвердить» в ВК.
4. Включите события: «Входящее сообщение», «Разрешение на сообщения», «Запрет на сообщения».

## Внешние источники данных

Если бот написан отдельно (aiogram, grammY, форма на сайте), данные можно слать напрямую.
Токен — в карточке бота.

```bash
curl -X POST https://<APP_URL>/api/ingest \
  -H "Authorization: Bearer <ingestToken>" \
  -H "Content-Type: application/json" \
  -d '{"externalId":"123","name":"Иван","phone":"+79991234567","email":"i@mail.ru","city":"Казань"}'
```

Обязателен только `externalId` — идентификатор человека в этом источнике.
Телефон нормализуется (`8 999…` и `+7 999…` — один и тот же номер), город приводится к
единому написанию, поэтому «Ёкатеринбург» и «екатеринбург» не расползутся на две записи.

## Устройство

| Что | Где |
| --- | --- |
| Схема БД | `prisma/schema.prisma` |
| Склейка контактов | `src/lib/contacts.ts` |
| Анкета | `src/lib/survey.ts` |
| Вызовы Telegram и ВК | `src/lib/platforms.ts` |
| Приём вебхуков | `src/app/api/webhooks/*` |
| Внешний приём данных | `src/app/api/ingest/route.ts` |
| Страницы админки | `src/app/(admin)/*` |

Модель `Message` уже пишет всю переписку в обе стороны — на ней строятся
следующие шаги: рассылки по фильтру (город, бот) и чат с пользователем из карточки.
